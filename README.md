# TFA-Quickbooks

Self-hosted accounting software for TFA (a holding company) — a QuickBooks replacement built around a real double-entry ledger: chart of accounts, bank-statement import, transaction categorization, and the core financial statements (Balance Sheet, P&L, Cash Flow). Planned stack: Next.js + TypeScript + Prisma + PostgreSQL, deployed on Railway.
